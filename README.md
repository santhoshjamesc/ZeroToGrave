# ZeroToGrave

A BitLife-style life-simulation game. Be born, grow up, study, work, fall in love, make mistakes, and die. Then continue as your heir.

Built with React Native + TypeScript (Expo). **Fully offline: no backend, no accounts, no network calls.** Saves live on your device.

## Download

**[Download the Android APK (v1.0.0, ~80 MB)](releases/ZeroToGrave-v1.0.0.apk)**

1. Download the APK on your Android phone.
2. Open it and allow "Install unknown apps" for your browser or file manager if prompted.
3. Launch **ZeroToGrave**.

Notes:
- Release build for Android (arm64-v8a, armeabi-v7a, x86, x86_64).
- It is signed with the debug keystore, so it is meant for sideloading and testing, not for the Play Store.
- Not yet tested on a wide range of devices. Please report layout or audio issues.

## How it plays

Aging is **not** a tap-to-age button. Every year runs through a Year Loop, so you can't rush a life:

1. **Briefing**: what happened last year.
2. **Focus**: spend your yearly Focus Points (study, work, fitness, social, hobby, rest, family, side-hustle). Returns diminish.
3. **Decisions**: resolve the year's life events by picking between choices with trade-offs.
4. **Commit**: review the year, then age up.

Time-costing actions (activities, dating, job hunting, crime, check-ups, treatment) use one of 4 yearly action slots, which refill when you age up. Some things unlock only at the right age (jobs, college, dating, shop, crime).

## Features

- **Life systems**: education and majors, careers with promotions, romance (dating, marriage, kids, adoption, divorce), crime and prison, finance (tax, rent, mortgage, investments, pension), health (hidden conditions, check-ups, treatment, surgery), activities.
- **Variety**: 130+ careers, 20+ countries, 300+ life events by life stage, 26 diseases, injuries and addictions, 40+ personality traits, 40+ achievements. Events react to your traits, flags and past choices.
- **Visual**: a procedural avatar that ages and shows micro-expressions, animated stat bars, haptics and synthesised sound effects.
- **Legacy**: when you die, continue as an heir who inherits assets (after debts and 30% estate tax). A graveyard and cross-life achievements persist.
- **Saves**: 3 save slots, autosave on every change, crash-safe writes and versioned migrations.
- **Settings**: sound, music, haptics, and hardcore mode (hides risk hints).

## Run from source

```bash
npm install
npm run typecheck && npm run lint && npm test
npx expo run:android      # or: npx expo run:ios
```

## Build the release APK

Requires JDK 17 and the Android SDK. The native `android/` folder is generated by Expo (`npx expo prebuild`).

```bash
cd android
ANDROID_HOME=$HOME/Library/Android/sdk ./gradlew assembleRelease
# output: android/app/build/outputs/apk/release/app-release.apk
```
